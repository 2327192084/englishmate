## 已修复（2026-11-20）

| 问题                          | 修法                                                                                                                 | 验证          |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------- |
| 成就永远不解锁                | 新增 `src/services/achievements.ts`：组装统计上下文 → 跑 `evaluate()` → 写库；接入练习结算流程；结算页展示新解锁成就 | 新增 5 个单测 |
| 每日复习上限不生效            | `buildRound()` 加 `reviewLimit` 参数，到期复习路径按上限截断；练习页与复习页均传入 `dailyReviewLimit - 今日已复习`   | 新增 3 个单测 |
| README 说 8 个词库（实际 16） | 更新为 16 个并列出具体分类                                                                                           | —             |

### 修的过程中测试抓到的两个 bug

1. **`reviewLimit: 0` 被当成"不限"** —— 原判据写的是 `reviewLimit > 0`，把 0 排除掉了。但 0 是有效值（表示今天不再复习），只有 `undefined` 才是"不限"。改为 `== null` 判断。

2. **全新用户白得「一丝不苟」成就** —— 没有练习时 `accuracy` 按约定返回 1（避免除零），成就判定直接用它，导致一打开 App 就有成就。修法是给该成就加前置条件 `totalSessions > 0 && totalWords > 0`，而不是改统计语义。
